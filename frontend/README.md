# Tell Your Boss

A lively quiz for rating a manager across seven corporate dimensions. Thirty-five questions, a scorecard, and a shareable archetype. No accounts. UI only for now.

## Dimensions

1. Leadership Style & Vibes
2. Communication Style
3. Feedback Style
4. Personality & Workspace Vibes
5. Innovation & Risk Appetite
6. Career Growth & Advocacy
7. Team Shielding & Politics

Each dimension has five parameters scored 1–5 with punchy labels.

## Stack

- Expo + React Native + TypeScript
- AsyncStorage for completed scorecard counts

## Run locally

```bash
cd frontend
npm install
npm start
```
